# Motion Detection System using PIR Sensor

## Overview
Designed and developed a motion detection system using a PIR sensor and transistor-based switching circuit. The system detects human movement through infrared sensing and activates an LED and buzzer as alerts, demonstrating sensor interfacing, transistor switching, and basic automation concepts.

## Components Used
- PIR Sensor
- BC547 Transistor
- LED
- Buzzer
- Resistors
- Power Supply

## Features
- Human motion detection
- Instant visual and audio alerts
- Low power consumption
- Simple hardware implementation

## Working Principle
The PIR sensor detects changes in infrared radiation caused by human movement. The transistor amplifies the signal and switches the LED and buzzer ON whenever motion is detected.
